# 隐私、记忆与数据保留

## 数据最小化

- OAuth Token 加密保存；
- AgentRun 只读取当前 Mission 授权数据；
- 不同客户默认不共享完整上下文；
- 模型调用记录保存哈希、用量和结构化结果，不保存隐式推理；
- 日志禁止记录密钥和完整 Token；
- 附件按需获取，不默认永久复制全部内容。

## 记忆治理

AgentProfile 长期存在，AgentRun 临时存在。Run 结束后：

保留：成果、Evidence、Skill 版本、质量、审计和经老板批准的结构化记忆。

清理：临时上下文、短期 ToolGrant、任务级访问令牌和未批准的记忆候选。

## 删除

运营数据删除接口要求明确确认，并保留必要审计记录。生产使用前必须由组织确定：

- 邮件正文保留期；
- 附件保留期；
- 模型调用元数据保留期；
- 审计保留期；
- 法律保留/诉讼保全规则；
- 用户导出与删除 SLA。
